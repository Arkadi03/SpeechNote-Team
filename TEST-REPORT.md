# Отчёт о проверке SpeechNote v2

Проверка выполнена локально на Windows 27 ноября 2026 года. Использовано существующее Python-окружение, русская tiny, FFmpeg и изолированный профиль Edge. Порт v2 — 8002.

| Сценарий | Наблюдение |
| --- | --- |
| Сервер и вкладки | Сервер завершил прогрев и вернул ready. Кнопки открыли все три раздела. Текст из конференции сохранился после настроек; совещание открылось со своим пустым текстом. |
| Русский WAV | Загрузка через интерфейс конференции вернула «Добрый день! Сегодня мы проверяем запись голоса. Это учебный проект. Один. два. три.» |
| Поток микрофона | Виртуальный вход Edge с тем же WAV передал 345 088 байт PCM в совещание и вернул русские фразы. Именно в v2 физический микрофон заново не проверялся. |
| Действия | Буфер обмена и скачанный UTF-8 TXT совпали с расшифровкой. Проверены очистка и сообщение при повреждённом WAV. |
| Настройки | Приложение отклонило пустое имя и удалённый HTTP-адрес; редактирование URL очистило поле токена. Тест использовал временный случайный ключ. |
| API вопросов | Через браузер прошли настоящий HTTP POST и CORS-проверка на локальном **стенде протокола**. Стенд проверил путь /v1/chat/completions, Bearer-заголовок, имя тестовой модели и наличие распознанного текста. Успешный ответ отобразился в панели. Проверены отсутствие текста, HTTP 401 и недоступность адреса. |
| Диаризация без моделей | Установленный WhisperLiveKit содержит Diart и Sortformer. В текущем Python отсутствуют diart, nemo и onnx; доступен onnxruntime. Сервер сообщил diarization_available=false; переключатель заблокирован, принудительный REST-запрос вернул HTTP 400, WebSocket — сообщение об ошибке. |
| Метки голосов | Настоящий форматтер обработал тестовые сегменты 1, 2 и -1: первые два получили A/B, у третьего подписи нет. Входные метки в этой проверке заданы вручную. |
| Linux | Синтаксис POSIX-запуска проверен через sh -n. WSL не вернула установленного дистрибутива. Установка пакетов, доступ к устройствам, скорость и полноценный запуск на Ubuntu не проверялись. |

**Что осталось подтвердить на защите.** Ввести реквизиты действующего провайдера с разрешённым CORS и получить содержательные вопросы по выступлению; установить NeMo и веса в отдельной среде и проверить двух собеседников; повторить запуск и загрузку WAV на Ubuntu. Внешний API-токен не предоставлялся, локальных слушателей на стандартных портах 11434 и 1234 не обнаружено. Контролируемый HTTP-ответ проверяет клиентский код, но не запуск языковой модели или качество вопросов.

Повторяемая браузерная проверка для Windows с Microsoft Edge, работающим базовым сервером и окружением из соседней папки:

```powershell
..\SpeechNote\.venv\Scripts\python.exe -B tests\speechnote_v2_browser.py
```

Если у v2 собственное окружение, используйте `.\.venv\Scripts\python.exe` в той же команде. Тест запускайте из корня v2. Для сдачи используйте свежие результаты конкретной командной сборки.
