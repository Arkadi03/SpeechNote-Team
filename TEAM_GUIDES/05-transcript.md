# Участник 5. Текст

1. Выполните разделы «Подключение» и «Своя ветка» в [инструкции PyCharm](00-PyCharm.md). Имя вашей ветки — `feature/transcript`.
2. В левой панели Project откройте `whisperlivekit/web/sn-transcript.js`. Все три коммита касаются этого файла.
3. Запустите командную копию по README на порту 8001. После каждого изменения сохраните файл (Ctrl+S) и обновите страницу (Ctrl+F5).

## 1. Переключать пустое состояние

Нажмите Ctrl+F, найдите `/* ШАГ 5.1 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 5.1 */
```

Вставьте на его место следующий код.

```js
    SN.el("empty").hidden = Boolean(text() || draft);
```

Проверка. Загрузите контрольный WAV. После появления текста подсказка о пустой записи скрывается.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-transcript.js`, изучите разницу и нажмите Commit с сообщением **Переключать пустое состояние**.

## 2. Отфильтровать тишину в подтверждённых строках

Нажмите Ctrl+F, найдите `/* ШАГ 5.2 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 5.2 */
    current = (snapshot.lines || []).map(line => line.text || "").join(" ");
```

Вставьте на его место следующий код.

```js
    current = (snapshot.lines || [])
      .filter(line => Number(line.speaker) !== -2 && line.text)
      .map(line => line.text.trim()).filter(Boolean).join("\n");
```

Проверка. В консоли браузера выполните SN.transcript.update({lines:[{speaker:-2,text:"тишина"},{speaker:1,text:"Привет"}]}). Видна только строка «Привет».

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-transcript.js`, изучите разницу и нажмите Commit с сообщением **Отфильтровать тишину в подтверждённых строках**.

## 3. Вывести предварительные слова

Нажмите Ctrl+F, найдите `/* ШАГ 5.3 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 5.3 */
```

Вставьте на его место следующий код.

```js
    draft = (snapshot.buffer_transcription || "").trim();
```

Проверка. В консоли выполните SN.transcript.update({lines:[],buffer_transcription:"Проверка"}). Слово появится в области предварительного текста.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-transcript.js`, изучите разницу и нажмите Commit с сообщением **Вывести предварительные слова**.

После трёх проверок выполните Push и откройте PR по [инструкции PyCharm](00-PyCharm.md). Опишите своими словами результат каждой проверки и укажите использование выданных заготовок.
