# Участник 1. Страница

1. Выполните разделы «Подключение» и «Своя ветка» в [инструкции PyCharm](00-PyCharm.md). Имя вашей ветки — `feature/page`.
2. В левой панели Project откройте `whisperlivekit/web/speechnote.html`. Все три коммита касаются этого файла.
3. Запустите командную копию по README на порту 8001. После каждого изменения сохраните файл (Ctrl+S) и обновите страницу (Ctrl+F5).

## 1. Добавить фирменную шапку

Нажмите Ctrl+F, найдите `<!-- ШАГ 1.1 -->`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
<!-- ШАГ 1.1 -->
```

Вставьте на его место следующий код.

```html
    <a class="brand" href="./" aria-label="SpeechNote — главная"><span class="mark" aria-hidden="true"><i></i><i></i><i></i><i></i><i></i></span>SpeechNote</a>
```

Проверка. В верхней строке появится ссылка SpeechNote. Нажмите её до начала записи.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/speechnote.html`, изучите разницу и нажмите Commit с сообщением **Добавить фирменную шапку**.

## 2. Представить студию и кафедры ТПУ

Нажмите Ctrl+F, найдите `<!-- ШАГ 1.2 -->`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
<!-- ШАГ 1.2 -->
```

Вставьте на его место следующий код.

```html
    <div class="intro"><p class="eyebrow">Цифровые кафедры ТПУ</p>
      <h1>Студия транскрибации</h1>
      <p>Запишите речь или выберите аудиофайл, чтобы получить текст на русском языке.</p>
    </div>
```

Проверка. Под шапкой найдите название студии, принадлежность к ТПУ и пояснение для пользователя.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/speechnote.html`, изучите разницу и нажмите Commit с сообщением **Представить студию и кафедры ТПУ**.

## 3. Указать университет и авторов движка

Нажмите Ctrl+F, найдите `<!-- ШАГ 1.3 -->`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
<!-- ШАГ 1.3 -->
```

Вставьте на его место следующий код.

```html
  <footer class="frame"><span>Томский политехнический университет</span><span>Распознавание на базе <a href="https://github.com/QuentinFuxa/WhisperLiveKit">WhisperLiveKit</a></span></footer>
```

Проверка. Внизу страницы проверьте название университета и адрес ссылки WhisperLiveKit.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/speechnote.html`, изучите разницу и нажмите Commit с сообщением **Указать университет и авторов движка**.

После трёх проверок выполните Push и откройте PR по [инструкции PyCharm](00-PyCharm.md). Опишите своими словами результат каждой проверки и укажите использование выданных заготовок.
