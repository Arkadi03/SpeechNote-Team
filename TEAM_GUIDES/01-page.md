# Страницы и оформление

Ветка `v2/ui`. Начните с [общего порядка в PyCharm и плана перехода](Переход.md). Каждый шаг — одно самостоятельное изменение и один личный коммит. Откройте указанный путь в своей ветке. При создании нового файла используйте тот же путь. Ссылки ведут на полную реализацию v2 для сверки.

## 1. Собрать шапку и две студии

Файл [whisperlivekit/web/speechnote.html](../whisperlivekit/web/speechnote.html), ориентир в v2 — строка 18. Выполните старые метки 1.1–1.3. Перед intro добавьте nav, задайте id studio, title и description. Сохраните все id существующих кнопок.

Фрагмент для сверки:

```
    <nav class="modes" aria-label="Разделы студии">
      <button data-mode="meeting" aria-pressed="true">Совещание</button>
      <button data-mode="conference" aria-pressed="false">Конференция</button>
      <button data-mode="settings" aria-pressed="false">Настройки</button>
```

**Проверка.** Проверьте название ТПУ, доступность двух источников звука и трёх кнопок навигации.

**Сообщение коммита:** «Собрать шапку и две студии».

## 2. Оформить интерфейс для телефона

Файл [whisperlivekit/web/speechnote.css](../whisperlivekit/web/speechnote.css), ориентир в v2 — строка 444. Закончите метки 2.1–2.3, добавьте стили режимов, активной кнопки, поля пароля и окна вопросов в конец CSS.

Фрагмент для сверки:

```
.modes { display:flex; flex-wrap:wrap; gap:8px; margin-top:24px; }
.modes [aria-pressed="true"] { background:var(--accent); color:var(--ink); }
.extra { margin-top:20px; }
.extra p { color:var(--muted); }
```

**Проверка.** Сравните ширину окна 375 и 1280 пикселей, проверьте видимость фокуса.

**Сообщение коммита:** «Оформить интерфейс для телефона».

## 3. Добавить форму настроек и область вопросов

Файл [whisperlivekit/web/speechnote.html](../whisperlivekit/web/speechnote.html), ориентир в v2 — строка 52. Перед help вставьте обе секции из v2. Согласуйте id с участниками 4 и 5. Подключите их скрипты в конце HTML и в списке сборщика web_interface.py.

Фрагмент для сверки:

```
    <section id="conference-tools" class="card extra" hidden>
      <h2>Вопросы к выступлению</h2>
      <p>По нажатию кнопки текст конференции будет отправлен выбранному API.</p>
      <button id="generate">Сгенерировать вопросы</button>
```

**Проверка.** Проверьте полученный HTML в браузере. В собранной странице видны все поля, скрипты встроены.

**Сообщение коммита:** «Добавить форму настроек и область вопросов».

## 4. Связать разделы с текущей записью

Файл [whisperlivekit/web/speechnote.js](../whisperlivekit/web/speechnote.js), ориентир в v2 — строка 28. После цикла выбора источника добавьте обработчики режимов. Используйте SN.transcript.select для двух студий, блокируйте переход при SN.busy.

Фрагмент для сверки:

```
SN.mode = "meeting";
const sections = {
  meeting:["Совещание", "Запишите речь или выберите аудиофайл, чтобы получить текст на русском языке."],
  conference:["Конференция", "Распознайте выступление и подготовьте вопросы по его содержанию."],
```

**Проверка.** Во время записи переход заблокирован; после остановки можно открыть настройки и вернуться.

**Сообщение коммита:** «Связать разделы с текущей записью».
