# Генерация вопросов

Ветка `v2/questions`. Начните с [общего порядка в PyCharm и плана перехода](Переход.md). Каждый шаг — одно самостоятельное изменение и один личный коммит. Откройте указанный путь в своей ветке. При создании нового файла используйте тот же путь. Ссылки ведут на полную реализацию v2 для сверки.

## 1. Проверить материал конференции

Файл [whisperlivekit/web/sn-questions.js](../whisperlivekit/web/sn-questions.js), ориентир в v2 — строка 19. Создайте модуль и обработчик generate. Читайте только текущий текст конференции. Отобразите ошибки пустого текста и конфигурации.

Фрагмент для сверки:

```
    if (!text) { status.textContent = "Сначала запишите речь или распознайте файл в разделе «Конференция»."; return; }
    let config;
    try { config = SN.llmConfig(); } catch (error) { status.textContent = error.message; return; }
    const {model, url, headers} = config;
```

**Проверка.** Попробуйте пустую конференцию, затем конференцию с текстом и пустым именем модели.

**Сообщение коммита:** «Проверить материал конференции».

## 3. Разобрать ответ и ошибки

Файл [whisperlivekit/web/sn-questions.js](../whisperlivekit/web/sn-questions.js), ориентир в v2 — строка 41. Отобразите содержание через textContent. Обработайте статус, не-JSON, пустой ответ и ошибку сети.

**Проверка.** Проверьте 401 с тестовым сервисом и закрытый порт. Отметьте, какие проверки выполнены с реальной моделью.

## 4. Синхронизировать вопросы и исходный текст

Файл [whisperlivekit/web/sn-questions.js](../whisperlivekit/web/sn-questions.js), ориентир в v2 — строка 9. Запомните текст запроса, очистите устаревший результат при его изменении, блокируйте повторное нажатие до finally.

Фрагмент для сверки:

```

      output.textContent = "";
      status.textContent = "";
    }
```

**Проверка.** После ответа очистите или дополните конференцию. Устаревший результат должен исчезнуть.

**Сообщение коммита:** «Синхронизировать вопросы и исходный текст».
