# Виртуализация и Ubuntu в WSL 2

Подготовьте время для перезагрузки. Сохраните открытые документы. Если на устройстве включено шифрование BitLocker, заранее проверьте доступ к ключу восстановления устройства. На учебном компьютере с управляемой прошивкой обратитесь к администратору.

1. Откройте Диспетчер задач (Ctrl+Shift+Esc) → Производительность → ЦП. Посмотрите строку **Виртуализация**. При значении «Включено» сразу переходите к шагу 4.
2. В Windows 11 откройте Параметры → Система → Восстановление → Расширенные параметры запуска → Перезагрузить сейчас. Затем выберите Поиск и устранение неисправностей → Дополнительные параметры → Параметры встроенного ПО UEFI → Перезагрузить.
3. На этом ПК установлен процессор Intel. В меню CPU, Advanced или Security найдите **Intel Virtualization Technology**, **VT-x** или **VMX**. Выберите **Enabled** и **Save & Exit**. Название и расположение зависят от прошивки. Если пункт скрыт или защищён паролем, уточните путь у производителя или администратора. После загрузки Windows снова посмотрите строку виртуализации. [Памятка Microsoft по UEFI](https://support.microsoft.com/en-us/windows/enable-virtualization-on-windows-c5578302-6e43-4b4b-a449-8ced115f58e1)
4. Откройте PowerShell от имени администратора. Выполните `wsl --install -d Ubuntu`. При запросе Windows перезагрузите компьютер. Запустите Ubuntu из меню «Пуск». Создайте имя Linux-пользователя и пароль. При вводе пароля символы на экране скрыты.
5. В **PowerShell** выполните `wsl -l -v`. Для Ubuntu ожидается VERSION **2**. Если указана 1, выполните `wsl --set-version Ubuntu 2`. Для проверки версии Linux введите `wsl -d Ubuntu -- cat /etc/os-release`. Сохраните вывод обеих команд для преподавателя. Название дистрибутива в командах должно совпадать со списком.
6. При сообщении об отсутствии компонента откройте «Включение или отключение компонентов Windows», включите «Платформа виртуальной машины» и «Подсистема Windows для Linux», подтвердите и перезагрузитесь. Если загрузка Ubuntu застряла на 0 %, используйте `wsl --install --web-download -d Ubuntu`. [Установка WSL по инструкции Microsoft](https://learn.microsoft.com/en-us/windows/wsl/install)
7. Для работы внутри Ubuntu клонируйте командный репозиторий в отдельный Linux-каталог, например ~/SpeechNote-Team, и создайте собственное Linux-окружение по разделу Linux в README. Для одновременной работы назначьте Linux-серверу порт 8002. Windows-эталон использует свою папку, окружение и порт 8000. После перезагрузки его можно снова запустить штатным start-speechnote.ps1.
