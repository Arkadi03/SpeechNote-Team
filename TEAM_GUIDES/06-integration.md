# Координатор, запуск и проверка

Ветка `v2/integration`. Начните с [общего порядка в PyCharm и плана перехода](Переход.md). Каждый шаг — одно самостоятельное изменение и один личный коммит. Откройте указанный путь в своей ветке. При создании нового файла используйте тот же путь. Ссылки ведут на полную реализацию v2 для сверки.

## 1. Развести порты и окружения Windows

Файл [start-speechnote.ps1](../start-speechnote.ps1), ориентир в v2 — строка 6. Выберите порт 8002, предусмотрите собственное окружение и чтение готового окружения эталона. Добавьте флаг Diarization.

Фрагмент для сверки:

```
    $runtime = ".venv"
    if (!(Test-Path -LiteralPath $python)) {
        $runtime = "../SpeechNote/.venv"
        $python = Join-Path $runtime "Scripts/python.exe"
```

**Проверка.** Проверьте запуск с кириллицей в пути, /health и контрольный WAV.

**Сообщение коммита:** «Развести порты и окружения Windows».

## 2. Подготовить запуск на Linux

Файл [start-speechnote.sh](../start-speechnote.sh), ориентир в v2 — строка 11. Создайте POSIX-скрипт с проверками Python и FFmpeg и передачей флагов. Укажите команды установки CPU-версий библиотек.

Фрагмент для сверки:

```
exec "$python" -B -m whisperlivekit.basic_server --host 127.0.0.1 --port 8002 \
    --model tiny --language ru --backend faster-whisper --backend-policy localagreement \
    --pcm-input --log-level INFO --warmup-file examples/speechnote-ru.wav "$@"
```

**Проверка.** Проверьте sh -n start-speechnote.sh. При наличии Ubuntu отдельно выполните полный запуск и распознавание.

**Сообщение коммита:** «Подготовить запуск на Linux».

**Сообщение коммита:** «Проверить API и браузерные сценарии».

## 4. Оформить комплект для защиты

Файл [README.md](../README.md), ориентир в v2 — строка 24. Сверьте командный README, карточки, план и отчёт. Архивируйте web вместе с вложенными ресурсами. Укажите фактические шесть PR.

Фрагмент для сверки:

```
## Демонстрация

1. Откройте «Совещание». Разрешите микрофон, произнесите фразу и остановите запись. Дождитесь завершения обработки. Скопируйте текст или нажмите «Скачать TXT».
2. Откройте «Конференция» → «Аудиофайл» и загрузите [русский контрольный WAV](examples/speechnote-ru.wav). Вернитесь в «Совещание» и убедитесь, что текст встречи сохранился отдельно.
```

**Проверка.** Распакуйте ZIP отдельно, сверьте содержимое с web и выполните сценарий демонстрации объединённой версии.

**Сообщение коммита:** «Оформить комплект для защиты».

В PR перечислите собственные изменения и наблюдения. Укажите использование подготовленных с ИИ заготовок.
