# Участник 4. Аудиофайл

1. Выполните разделы «Подключение» и «Своя ветка» в [инструкции PyCharm](00-PyCharm.md). Имя вашей ветки — `feature/audio-file`.
2. В левой панели Project откройте `whisperlivekit/web/sn-file.js`. Все три коммита касаются этого файла.
3. Запустите командную копию по README на порту 8001. После каждого изменения сохраните файл (Ctrl+S) и обновите страницу (Ctrl+F5).

## 1. Показать имя выбранной записи

Нажмите Ctrl+F, найдите `/* ШАГ 4.1 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 4.1 */
  input.onchange = controls;
```

Вставьте на его место следующий код.

```js
  input.onchange = () => {
    SN.el("filename").textContent = input.files[0]?.name || "Выбрать аудиофайл";
    SN.notice("");
    controls();
  };
```

Проверка. Перейдите в Аудиофайл, выберите examples/speechnote-ru.wav. Имя отобразится и станет доступна отправка.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-file.js`, изучите разницу и нажмите Commit с сообщением **Показать имя выбранной записи**.

## 2. Проверить размер файла

Нажмите Ctrl+F, найдите `/* ШАГ 4.2 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 4.2 */
```

Вставьте на его место следующий код.

```js
    if (!file.size) { SN.notice("Выбран пустой файл.", true); return; }
    if (file.size > 512 * 1024 * 1024) { SN.notice("Размер файла превышает 512 МБ.", true); return; }
```

Проверка. Создайте пустой файл с расширением wav и выберите его. После нажатия появится «Выбран пустой файл».

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-file.js`, изучите разницу и нажмите Commit с сообщением **Проверить размер файла**.

## 3. Объяснить ошибки обработки файла

Нажмите Ctrl+F, найдите `/* ШАГ 4.3 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 4.3 */
      if (!response.ok) throw new Error("Ошибка загрузки");
```

Вставьте на его место следующий код.

```js
      if (!response.ok) {
        const messages = {400:"Проверьте формат и содержимое аудиофайла.", 401:"Сервер запросил авторизацию.", 408:"Сервер не успел обработать запись.", 413:"Файл слишком большой.", 503:"Сервер занят. Повторите позже."};
        throw new Error(messages[response.status] || "Ошибка сервера (HTTP " + response.status + ").");
      }
```

Проверка. Сохраните обычный текст под именем bad.wav и загрузите. Должно появиться сообщение об ошибке формата; затем попробуйте контрольный WAV.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-file.js`, изучите разницу и нажмите Commit с сообщением **Объяснить ошибки обработки файла**.

После трёх проверок выполните Push и откройте PR по [инструкции PyCharm](00-PyCharm.md). Опишите своими словами результат каждой проверки и укажите использование выданных заготовок.
