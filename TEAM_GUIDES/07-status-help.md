# Участник 7. Статус и справка

1. Выполните разделы «Подключение» и «Своя ветка» в [инструкции PyCharm](00-PyCharm.md). Имя вашей ветки — `feature/status-help`.
2. В левой панели Project откройте `whisperlivekit/web/sn-status.js`. Все три коммита касаются этого файла.
3. Запустите командную копию по README на порту 8001. После каждого изменения сохраните файл (Ctrl+S) и обновите страницу (Ctrl+F5).

## 1. Проверить готовность сервера

Нажмите Ctrl+F, найдите `/* ШАГ 7.1 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 7.1 */
      throw new Error("Проверка ещё не подключена");
```

Вставьте на его место следующий код.

```js
      const response = await fetch(SN.endpoint("health"), {cache: "no-store", signal: AbortSignal.timeout(5000)});
      if (!response.ok || !(await response.json()).ready) throw new Error();
```

Проверка. Откройте страницу и проверьте надпись «Сервер готов». В отдельной вкладке откройте /health и найдите ready.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-status.js`, изучите разницу и нажмите Commit с сообщением **Проверить готовность сервера**.

## 2. Обновлять статус при изменении связи

Нажмите Ctrl+F, найдите `/* ШАГ 7.2 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 7.2 */
```

Вставьте на его место следующий код.

```js
  document.addEventListener("sn-check", check);
  window.addEventListener("online", check);
  window.addEventListener("offline", check);
  document.addEventListener("visibilitychange", () => { if (!document.hidden) check(); });
  setInterval(() => { if (!document.hidden) check(); }, 30000);
```

Проверка. В DevTools → Network выберите Offline. Верните No throttling и переключитесь на другую вкладку и обратно. Проверьте оба состояния индикатора.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-status.js`, изучите разницу и нажмите Commit с сообщением **Обновлять статус при изменении связи**.

## 3. Добавить инструкцию пользователя

Нажмите Ctrl+F, найдите `/* ШАГ 7.3 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 7.3 */
```

Вставьте на его место следующий код.

```js
  const steps = [
    "Для записи нажмите «Начать запись», разрешите браузеру использовать микрофон и произнесите несколько фраз. Нажмите «Остановить» и дождитесь завершения.",
    "Для готовой записи выберите «Аудиофайл», укажите файл и нажмите «Распознать файл». Новый результат добавится после предыдущего.",
    "Пока идёт запись, предварительные слова выделяются курсивом и могут измениться. После завершения скопируйте текст или скачайте его в TXT. Обновление страницы очищает расшифровку.",
    "Если микрофон недоступен, проверьте разрешение в браузере и выбранное устройство Windows. Открывайте SpeechNote через localhost или HTTPS."
  ];
  const list = document.createElement("ol");
  for (const step of steps) {
    const li = document.createElement("li");
    li.textContent = step;
    list.append(li);
  }
  SN.el("help-text").append(list);
```

Проверка. Раскройте «Как пользоваться SpeechNote». Проверьте четыре пункта и работу клавиши Enter на заголовке.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-status.js`, изучите разницу и нажмите Commit с сообщением **Добавить инструкцию пользователя**.

После трёх проверок выполните Push и откройте PR по [инструкции PyCharm](00-PyCharm.md). Опишите своими словами результат каждой проверки и укажите использование выданных заготовок.
