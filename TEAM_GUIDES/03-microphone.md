# Участник 3. Микрофон

1. Выполните разделы «Подключение» и «Своя ветка» в [инструкции PyCharm](00-PyCharm.md). Имя вашей ветки — `feature/microphone`.
2. В левой панели Project откройте `whisperlivekit/web/sn-mic.js`. Все три коммита касаются этого файла.
3. Запустите командную копию по README на порту 8001. После каждого изменения сохраните файл (Ctrl+S) и обновите страницу (Ctrl+F5).

## 1. Подписать состояния записи

Нажмите Ctrl+F, найдите `/* ШАГ 3.1 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 3.1 */
    button.textContent = active ? "Остановить" : "Начать запись";
```

Вставьте на его место следующий код.

```js
    const labels = {connecting:"Отменить", recording:"Остановить", finishing:"Завершение…"};
    button.textContent = labels[active?.phase] || "Начать запись";
```

Проверка. Нажмите запись и разрешите микрофон. Надпись меняется на «Остановить», после остановки возвращается исходная.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-mic.js`, изучите разницу и нажмите Commit с сообщением **Подписать состояния записи**.

## 2. Показать длительность записи

Нажмите Ctrl+F, найдите `/* ШАГ 3.2 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 3.2 */
```

Вставьте на его место следующий код.

```js
    s.started = Date.now();
    SN.el("timer").textContent = "00:00";
    s.clock = setInterval(() => {
      const sec = Math.floor((Date.now() - s.started) / 1000);
      SN.el("timer").textContent = [Math.floor(sec / 60), sec % 60].map(n => String(n).padStart(2, "0")).join(":");
    }, 250);
```

Проверка. При записи счётчик увеличивается, после остановки время фиксируется.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-mic.js`, изучите разницу и нажмите Commit с сообщением **Показать длительность записи**.

## 3. Остановить отправку при переполнении очереди

Нажмите Ctrl+F, найдите `/* ШАГ 3.3 */`, затем Esc. Замените следующий блок целиком, включая строку метки.

```
/* ШАГ 3.3 */
```

Вставьте на его место следующий код.

```js
    if (s.socket.bufferedAmount > 4 * 1024 * 1024) {
      end(s, "Соединение слишком медленное. Сохранён подтверждённый текст.");
      return;
    }
```

Проверка. Проверьте обычную запись. Разберите условие: при очереди больше 4 МиБ вызывается end и текущий блок не отправляется.

Откройте Commit (Ctrl+K), отметьте только `whisperlivekit/web/sn-mic.js`, изучите разницу и нажмите Commit с сообщением **Остановить отправку при переполнении очереди**.

После трёх проверок выполните Push и откройте PR по [инструкции PyCharm](00-PyCharm.md). Опишите своими словами результат каждой проверки и укажите использование выданных заготовок.
