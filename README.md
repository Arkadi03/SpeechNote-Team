# SpeechNote v2 · Цифровые кафедры ТПУ

Локальная студия на WhisperLiveKit 0.2.28 (Quentin Fuxa и соавторы). Встречи и конференции распознаются многоязычной моделью tiny на русском языке. Каждая вкладка ведёт свой текст. Обе используют одну цепочку распознавания, принимают микрофон и аудиофайлы, поддерживают буфер обмена, TXT и очистку.

## Запуск в Windows на подготовленном компьютере

Откройте PowerShell в каталоге **SpeechNote-v2**.

```powershell
.\start-speechnote.ps1
```

Откройте [SpeechNote v2](http://127.0.0.1:8002/). Для другого порта добавьте `-Port 8003`. Скрипт предпочитает локальную `.venv`; на этом компьютере использует Python и кеш модели из соседней `../SpeechNote/.venv`. Исходники загружаются из v2. Порты 8000 и 8001 относятся к прежним версиям.

На новом ПК нужны 64-разрядный Python 3.11–3.13, FFmpeg в PATH и исходники v2. Команды из корня:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\hf.exe download Systran/faster-whisper-tiny config.json tokenizer.json vocabulary.txt model.bin --revision d90ca5fe260221311c53c58e660288d3deb8d356 --local-dir .venv/faster-whisper-tiny
.\start-speechnote.ps1
```

## Демонстрация

1. Откройте «Совещание». Разрешите микрофон, произнесите фразу и остановите запись. Дождитесь завершения обработки. Скопируйте текст или нажмите «Скачать TXT».
2. Откройте «Конференция» → «Аудиофайл» и загрузите [русский контрольный WAV](examples/speechnote-ru.wav). Вернитесь в «Совещание» и убедитесь, что текст встречи сохранился отдельно.
3. В «Настройках» укажите точный идентификатор модели провайдера и URL его OpenAI-совместимого API. Поддерживается базовый адрес, например `https://api.openai.com/v1`, или полный адрес `…/v1/chat/completions`. Для совместимой локальной службы используйте её реальный порт, например `http://localhost:11434/v1`. У провайдера должна быть запущена выбранная модель. Введите личный токен в скрытое поле, если сервис требует авторизации.
4. Вернитесь в «Конференцию» и нажмите «Сгенерировать вопросы». В этот момент браузер отправляет **только расшифровку конференции** выбранному провайдеру, имя модели и инструкцию для генерации. Каждый запрос использует тариф и лимиты этого провайдера. Результат выводится в отдельной области под расшифровкой. При изменении исходного текста прежний ответ очищается.
5. Пока идёт обработка, дождитесь её окончания перед сменой раздела. Настройки и тексты принадлежат текущей странице; обновление очищает их.

**Подключение API.** Запрос уходит непосредственно из браузера. Укажите доверенный адрес; для удалённого сервиса обязателен HTTPS. Сервис должен разрешать CORS для адреса страницы и заголовков Content-Type и Authorization. Например, для запуска здесь origin — `http://127.0.0.1:8002`. При ошибке проверьте доступность сервера, CORS и политику браузера для локальной сети. HTTP 401/403 указывает на проблему с доступом, 404 — с путём или именем модели, 429 — с лимитом. Для API, который запрещает браузерные вызовы, нужен совместимый шлюз под контролем владельца. [Формат Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)

**Токен.** Вводите его только в «Настройках». Приложение использует заголовок Authorization при запросе к указанному адресу; изменение адреса и уход со страницы очищают поле токена. Код приложения не сохраняет его в файле, localStorage или журнале. Не прикладывайте HAR, приватные ключи или скриншоты запросов с заголовками авторизации к PR.

## Диаризация

Переключатель общий для следующих записей и загрузок обеих вкладок в текущем браузере. Модель загружается при запуске сервера. В базовом профиле /health сообщает, что модель недоступна. В таком режиме переключатель заблокирован. В профиле с моделью переключатель включает настоящий конвейер WhisperLiveKit для конкретной сессии. Уже обработанный текст сохраняется как был. В потоковой записи положительные метки выводятся как «Говорящий 1», «Говорящий 2»; результат файла использует штатные обозначения A, B. Это метки внутри записи, а не личности людей.

WhisperLiveKit содержит бэкенды Diart и NeMo Sortformer. Для v2 предусмотрен профиль Sortformer и модель `nvidia/diar_streaming_sortformer_4spk-v2`. Дополнительные зависимости и веса потребуют места и времени. Для эксперимента создайте **собственное окружение v2**; готовое окружение Windows-эталона используется только для базового профиля. Предпочтительная площадка проверки NeMo — отдельная Ubuntu с Python 3.11 или 3.12. Команды после создания окружения:

```bash
.venv/bin/python -m pip install -e '.[diarization-sortformer]'
sh start-speechnote.sh --diarization --diarization-backend sortformer
```

Можно дополнительно передать `--sortformer-model-path /путь/к/модели.nemo`. В Windows при наличии совместимой установки NeMo в собственной v2/.venv предусмотрено `.\start-speechnote.ps1 -Diarization`. Тест разделения голосов требует записи с двумя реальными собеседниками. Одноголосый контрольный WAV проверяет распознавание текста.

## Ubuntu / Linux

Из корня исходников v2, при наличии Python 3.11–3.13 с venv и FFmpeg:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -e .
.venv/bin/hf download Systran/faster-whisper-tiny config.json tokenizer.json vocabulary.txt model.bin --revision d90ca5fe260221311c53c58e660288d3deb8d356 --local-dir .venv/faster-whisper-tiny
sh start-speechnote.sh
```

Для удалённой демонстрации запустите на клиентском ПК `ssh -N -L 8080:127.0.0.1:8002 user@server`, затем откройте http://127.0.0.1:8080. При прямом запросе к языковой модели localhost означает компьютер **с браузером**. Для сетевого доступа к веб-интерфейсу нужны HTTPS и проксирование WebSocket.
